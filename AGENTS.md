# Diretrizes do projeto

- Seguir a filosofia de código ponytail: manter o código simples, direto, coeso e fácil de prender, soltar, reorganizar e evoluir, evitando abstrações prematuras.
- Escrever o código, os nomes de domínio, os textos da interface e os comentários em português.
- Evitar comandos desnecessários de terminal.
- A validação de UX/UI é feita pelo usuário. Não tirar capturas de tela, a menos que isso seja solicitado explicitamente.
